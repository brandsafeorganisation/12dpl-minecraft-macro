# Real LAN play through the LAN helper (Windows PowerShell; here
# simulated with files by harness.cpp, and "the other PC" is the
# folder run/remote). Over the network is the default: Options >
# Multiplayer shows it. Open to LAN starts a host helper (its command
# line is printed) in cubeland_worlds\lan\h_<session>, where bob's
# lines arrive; Save and Quit tells it to stop. Then another PC hosts
# that world: Play Multiplayer starts a scan helper, which finds it
# (host, world, mode); Join Server starts a join helper, waits for the
# snapshot and loads the world with bob's block; bob's chat comes over
# the network; the host quitting is told in the chat. A firewall that
# blocks the host leaves the list empty, and a PC where PowerShell
# can't start says so on Play Multiplayer.
